# MapGame

A casual puzzle-roguelike for iOS and Android, built on the 55HP Unity Mobile Template.

## Concept
Explore a hex grid map using food as your movement resource. 
Every move costs food. Every hidden tile is a risk or a reward.
Complete your mission before you run out of supplies — or die trying.

## Core Mechanics
- Hex grid exploration (10×10 – 12×12)
- Food-based movement (cost = Chebyshev distance)
- Tile types: Battaglia, NPC, Mistery, Risorsa
- Two lose conditions: food exhausted or character death

## Status
Early prototype — hint mechanic in active development.

## Built With
Unity 2022.3 LTS · URP · iOS & Android
